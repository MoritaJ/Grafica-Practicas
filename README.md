# Grafica 07 Iluminación 

Para el de dasarollo de esta práctica,  Se implementaron los tres tipos de luz: direccional (luz global de la escena), puntual (luz roja y luz blanca de la lámpara) y spotlight (linterna de la cámara, faro azul del coche y foco amarillo del helicóptero).
